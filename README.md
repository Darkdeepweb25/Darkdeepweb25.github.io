# Diptansu Kumar — Interactive Cybersecurity Portfolio

Static, responsive portfolio built with plain HTML/CSS/JavaScript. No build step and no backend required.

## GitHub Pages

This repository is the personal-site repository for the GitHub account `Darkdeepweb25`. The intended site is:

https://darkdeepweb25.github.io/

The site is deployed from the `main` branch.

## Included

- Cybersecurity Analyst / VAPT-first positioning
- Web, Mobile and API security focus
- Interactive dark/light theme
- Responsive navigation and mobile menu
- Animated cyber-grid and terminal hero
- Experience timeline
- VAPT, Mobile/API and SOC/DFIR/GRC skills
- ACDRIP+ project showcase
- Certification vault
- LinkedIn proof-of-work gallery
- Resume link
- LinkedIn, GitHub and email CTAs

## Deployment

A GitHub Actions workflow is included in `.github/workflows/pages.yml` so future pushes to `main` can redeploy the static portfolio automatically once GitHub Pages is enabled for the repository.
